# astrbot_plugin_user_prompts

用户提示词：AstrBot 插件，让每位用户为当前对话设置自己的提示词。支持多行文本，用户之间独立配置，开启新会话后不继承。

## 安装

在 AstrBot 插件管理页，通过仓库地址安装：

```text
https://github.com/xmlans/astrbot_plugin_user_prompts
```

## 使用

1. 发送 `/prompt`。
2. 收到「请发送你想要添加/修改的提示词」后，单独发送完整提示词，可以包含换行。
3. 收到保存成功的提示后，正常聊天即可生效。

请在 5 分钟内发送提示词，超时后重新发送 `/prompt`。

| 命令 | 用途 |
| --- | --- |
| `/prompt` | 添加或修改提示词 |
| `/prompt show` | 查看当前提示词 |
| `/prompt clear` | 清除提示词并退出等待输入 |

## 配置

在插件管理页可设置：

- 是否启用插件。
- 是否开启白名单，以及允许使用的用户列表。
- 是否限制提示词字数，以及最大字数（默认 1000 字）。

白名单可填写用户 ID；推荐填写 `/prompt` 返回的平台用户标识。
